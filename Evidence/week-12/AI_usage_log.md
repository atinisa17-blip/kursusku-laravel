# LOG PENGGUNAAN ARTIFICIAL INTELLIGENCE (AI)

## Identitas
- Nama: Rasti Khairunnisa
- Mata Kuliah: Praktikum Pemrograman Web
- Materi: Laravel Relational Database
- Tools AI: ChatGPT

## Tujuan Penggunaan
ChatGPT digunakan sebagai alat bantu untuk memahami tahapan praktikum Laravel Relational Database pada proyek KursusKu.

## Bentuk Penggunaan AI
1. Membantu memahami pembuatan migration dan struktur tabel database.
2. Membantu memahami relasi antar-model menggunakan Eloquent ORM.
3. Memberikan penjelasan tentang penggunaan foreign key dan cascade delete.
4. Membantu memeriksa kode model dan controller.
5. Memberikan panduan pembuatan form dan penyimpanan data pendaftaran.
6. Membantu menguji validasi pendaftaran ganda.
7. Membantu memahami pengujian cascade delete pada data kursus dan peserta.

## Hasil Penggunaan
Dengan bantuan ChatGPT, saya dapat memahami tahapan praktikum dan menyelesaikan pengujian pada proyek KursusKu. Kode dan perintah yang diberikan dijalankan serta diperiksa kembali secara langsung pada proyek Laravel.

## Kesimpulan
ChatGPT digunakan sebagai alat bantu pembelajaran untuk memberikan penjelasan dan panduan selama praktikum. Pemahaman, penerapan kode, dan pengujian dilakukan secara langsung oleh mahasiswa.
