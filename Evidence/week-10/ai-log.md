# AI Usage Log

## Informasi Proyek
- Nama proyek: KursusKu Laravel
- Mata kuliah: Praktikum Pemrograman Web
- Framework: Laravel
- Database: MySQL
- Fitur utama: CRUD data kursus

## Penggunaan AI
AI digunakan sebagai alat bantu dalam proses pengembangan aplikasi, terutama untuk:
1. Membantu memahami struktur proyek Laravel.
2. Membantu menyusun migration dan model Course.
3. Membantu mengembangkan CourseController.
4. Membantu menyusun route dan tampilan Blade.
5. Membantu memahami validasi input.
6. Membantu menyusun dokumentasi dan test case.

## Verifikasi
Kode dan fitur aplikasi diperiksa serta diuji melalui browser dan database phpMyAdmin. Hasil pengujian dicatat berdasarkan fitur yang benar-benar dijalankan.

## Catatan
AI digunakan sebagai pendamping belajar. Pemahaman kode, pemeriksaan hasil, dan pengujian aplikasi tetap dilakukan oleh mahasiswa.
