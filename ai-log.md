# AI Log — Praktikum Laravel Database & CRUD I

## Identitas
- Nama: Rasti Khairunnisa
- Proyek: kursusku-laravel
- Materi: Model, Migration, dan CRUD Laravel

## Catatan Penggunaan AI

### 1. Konfigurasi Database
AI membantu menjelaskan konfigurasi koneksi database MySQL pada file `.env` dan cara memeriksa koneksi database Laravel.

### 2. Migration dan Struktur Tabel
AI membantu memeriksa struktur tabel `courses`, yang mencakup kolom `id`, `code`, `name`, `description`, `fee`, `quota`, `start_date`, `status`, `created_at`, dan `updated_at`.

### 3. Model dan Controller
AI membantu menjelaskan penggunaan model `Course`, pengaturan `$fillable`, serta fungsi controller untuk menampilkan, menambah, melihat detail, mengedit, dan menghapus data kursus.

### 4. Route dan View
AI membantu menjelaskan penggunaan resource route dan halaman Blade untuk daftar kursus, tambah kursus, detail kursus, dan edit kursus.

### 5. Pengujian CRUD
AI membantu menyusun langkah pengujian fitur Create, Read, Update, dan Delete pada aplikasi kursus.

### 6. Pengujian Validasi
AI membantu menguji penolakan kode kursus duplikat dan validasi ketika nama kursus wajib dikosongkan.

### 7. Pemeriksaan Database
AI membantu menjelaskan cara menggunakan phpMyAdmin untuk memeriksa struktur tabel dan data kursus yang tersimpan.

## Catatan
Saran AI digunakan sebagai panduan selama pengerjaan dan pengujian aplikasi. Hasil akhir diperiksa kembali melalui aplikasi Laravel dan database MySQL.
